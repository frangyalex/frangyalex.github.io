常用计算定理

在解决几何问题时，已知在三角形abc中，我们经常利用以下两个核心定理来求解未知量。

1. 正弦定理

用于已知一边及两角，或两边及其中一边的对角，求其他边和角。

a / sin(A) = b / sin(B) = c / sin(C) = 2R

其中 R 为三角形的外接圆半径。

2. 余弦定理

用于已知三角形的三边，或两边及其夹角，求第三边或其中一个角。

a² = b² + c² - 2bc·cos(A)

（注：此公式针对边a及其对角A）
